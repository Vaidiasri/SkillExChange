# Skill Exchange API

This project is a Skill Exchange API built with FastAPI and SQLAlchemy.

## Features

- User management (CRUD operations for users)
- Skill management (CRUD operations for skills)
- Junctions between users and skills (e.g., associating skills with users)
- Database interactions using SQLAlchemy
- API routing for users and skills
- Pydantic schemas for data validation and serialization
